2. Welche Daten werden gespeichert?

Die App speichert ausschließlich folgende Daten lokal auf Ihrem Gerät: • Spielernamen und optionale Vereinszugehörigkeiten • Turnierdaten (Name, Datum, Paarungen, Ergebnisse) • App-Einstellungen (Timer-Standard, Sprache) Es werden keine Daten an Server oder Dritte übertragen. Es findet keine Cloud-Synchronisierung statt.

3. Kein Tracking, keine Analyse

Die App enthält keinerlei Analyse-Tools, Werbe-SDKs oder Tracking-Mechanismen. Es werden keine Nutzungsstatistiken erhoben.

4. In-App-Käufe (Google Play)

Die App bietet ein jährliches Abonnement über den Google Play Store an. Zahlungsdaten und Kaufabwicklung werden ausschließlich von Google verarbeitet. Der Entwickler hat keinen Zugriff auf Zahlungsdaten.

5. Benachrichtigungen

Die Benachrichtigungsberechtigung wird ausschließlich verwendet, um den Ablauf des Rundenzeitmers anzuzeigen. Benachrichtigungsdaten verlassen das Gerät nicht.

6. Speicherzugriff

Die Speicherberechtigung wird ausschließlich verwendet, um vom Nutzer initiierte Backups zu exportieren oder zu importieren. Es werden keine Dateien ohne ausdrückliche Nutzeraktion gelesen oder geschrieben.

7. Datenlöschung

Alle lokal gespeicherten Daten können jederzeit über Einstellungen → Alle Daten zurücksetzen vollständig gelöscht werden. Eine Deinstallation der App entfernt ebenfalls alle gespeicherten Daten.

Privacy Policy

Last updated: February 2026

1. Data Controller

Tennisclub Turnier Manager Developer: Michael Seidenschnur Contact: tennis.turnier.manager@gmail.com

2. Data Collected

The app stores the following data locally on your device only: • Player names and optional club affiliations • Tournament data (name, date, pairings, results) • App settings (timer default, language) No data is transmitted to servers or third parties. There is no cloud synchronization.

3. No Tracking or Analytics

The app contains no analytics tools, advertising SDKs, or tracking mechanisms. No usage statistics are collected.

4. In-App Purchases (Google Play)

The app offers a yearly subscription via Google Play. Payment processing is handled exclusively by Google. The developer has no access to payment data.

5. Notifications

Notification permission is used solely to alert you when the round timer expires. No notification data leaves the device.

6. Storage Access

Storage permission is used only to export or import user-initiated backups. No files are accessed without explicit user action.

7. Data Deletion

All locally stored data can be deleted at any time via Settings → Reset all data. Uninstalling the app also removes all stored data.
